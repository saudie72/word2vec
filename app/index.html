Spend Grouper

Finds purchase lines that describe the same thing, even when buyers write it differently ("HEX SCREW M8 SS" and "Hx Scrw M8 Stainless"), then shows where several departments buy it from several vendors without a contract.

Sample data: 6,000 fictional purchase lines for a government agency. Everything runs in your browser; an uploaded file never leaves your computer.

How it works

1. Learn the wordsWord2Vec reads every description and gives each word an address of numbers. Words used in the same company, like "scrw" and "screw", end up with nearly the same address.
2. Group the linesEach description becomes the average of its word addresses, with rare words weighted up and units like "box" weighted down. Descriptions that point the same way are grouped.
3. Flag opportunitiesA group is flagged when at least 4 departments buy it from at least 3 vendors, with half or more of the spend off contract. These are candidates for a shared contract; a buyer should review each one.
